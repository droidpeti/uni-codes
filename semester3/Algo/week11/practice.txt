Starting Dictionary

While the algorithm is running, it is always true, that the word in variable a is inside the dictionary

Algorithm start

The B variable contains the most recently read charachter from the string

we store the next charachter of the string in the B variable
(if reading from the input fails, then we print a's code to the output)

Does the dictionary contain the concatination of aB?

if contains: 
    variable a content gets overwritten by the concatination aB
else: 
    we store the aB concatination in dictionary (with the next id)
    we print the code of the charachter stored in variable a
    we overwrite variable a's content with variable B's content

Algorithm end
