If Vertex A's distance d(A) gets better in step number n and A -> B edge exists (where the distance is c between A and B), then we
update d(B) to min(d(B, D(A) + c)). And is d(B) got smaller, then we update p(B) to A (where p(B) is the parent of B)

Floyd algorithm on the same graph

F0 -> ... -> F5 <- distance matrix 
P0 -> ... -> P5 <- neighbor matrix

When determining the Fn matrix, the values of the Fn-1 can't get updated, where
- they are in row or column n
- The values of the main diagonal (0)
- The select n column infinity (-) values
- The select n row infinity (-) values

If the value Fn-1[i,j] can get better,
then we need to compare it with
the sum of Fn-1[i, k] and Fn-1[k, j],
if Fn-1[i, k] + Fn-1[k, j] < Fn-1[i, j], we replace it with the sum 
(so we compare it to the value in the same value in row and col n (the sum of them))
and update Pn-1[i, j] to n-1
