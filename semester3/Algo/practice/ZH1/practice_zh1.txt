We insert an X key into the S tree,
like we would insert it into a regular search tree
After the insertion, we make the X key into the S tree's root,
by doing the following 3 rotations

A; The parent of the X key is the root of the S tree

        P
      /   \
     X     c
    / \
   a   b

Rotate

        X
      /   \
     a     p
          / \
         b   c

B; X is the child of it's parent (P) on the same side,
as P is the parent of it's Parent (G)

        G
       / \
      P   d
     / \
    X   c
   / \
  a   b

rotate

        X
       / \
      a   P 
         / \

as P is the parent of it's Parent (G)

Járjuk be az 1-es csúcsból indulva mélységi bejárással az alábbi gráfot!
A csúcsok szomszédjainak feldolgozási sorrendje legyen a csúcsok
címkéiben nagyság szerint növekedően rendezett.
Jelöljük a gráfon a bejárás során a csúcsokhoz rendelt mélységi és
befejezési számokat, és ezek alapján osztályozzuk a gráf éleit!

Grading edges:

fn: finishing number
dn: depth number

X -> Y
    -if dn[y] = 0 
        x -> y is a tree edge
    -if dn[y] <= dn[x] and fn[y] = 0
        x -> y is a back edge
    - if dn[y] > dn[x] and fn[y] != 0
        x -> y is a forward edge
    - if dn[y] < dn[x] and fn[y] != 0
        x -> y is a cross edge
