1. Feladat

Döntsük el az alábbi szimbólumsorozatokról, hogy formulának tekinthetők-e, és ha igen, negációs, konjunkciós, diszjunkciós, implikációs formulák-e?

konj: és
diszj: vagy

prioritások, csökkenő sorrendben:

! > && > || > =>

ha ugyanaz a szintje, akkor a legkissebb prioritású!

                  ____
a: P => Q => R && !(P) => P <= nem jó formula, mert zárójel csak binér összekötős formula körül lehet!

       1    0   0    1  1
b: (P || Q) || R && (!P => P) <= diszjunkciós formula

          _
c: P && Q !(Q || R) && !(P => P) <= nem jó formula, mert nincs operátor a negáció és az előtte lévő operandus között!

               _
d: (P => R) => ((Q => R) => (P || Q => R) <= nem jó formula, mert nincs lezárva egy zárójel!

     0     1     0  0   1     0
e: Q => (P && R) && !(P || R) || Q

3. Feladat

Lássuk be az alábbi formuláról, hogy tautológiák!

tautológia: mindig igaz

a: |=0 A => (B => A)

b: |=0 (A => B => C) => (A => B) => A => C

c: |=0 A => B => A && B

Megoldás:
    - igazságtáblával
    - igazságértékelési fával: a hamis halmaz üres
    - tautologikus ekvivalenciákkal: levezetjük a formulából a T-t
